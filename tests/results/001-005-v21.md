## Common Issues Found

### 1. Backend Errors (21 occurrences)
Complex SEARCH queries fail with "Sorry, an error occurred". Likely causes:
- Graph expansion timeout
- LLM response generation failure
- Memory/context limits

### 2. Wrong Language Responses (6 occurrences)
English input sometimes gets Russian response. Likely cause:
- action-response-prompt not enforcing language matching

### 3. SEARCH Treated as SAVE (4 occurrences)
Questions like "How much beef needed?" saved instead of searched:
- "How much" without "?" might not trigger SEARCH
- Need to strengthen question detection

### 4. Database Verification
All scenarios show Qdrant count = Neo4j count (items properly indexed)
