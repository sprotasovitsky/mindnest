## Root Causes

### 1. Task Completion Only Works for First Match
- Andrey had 4 separate tasks, only "Rent karaoke" was marked DONE
- `complete_task_by_title` uses semantic search and completes first match
- User message "Done with my task!" finds one task, not all

**Fix needed**: Either:
- Create single combined task instead of 4 separate
- Or modify prompt to have LLM call completion for each task separately

### 2. Vika's Task Not Completed
- "My task is done!" didn't match "Buy all food" well enough
- Semantic search threshold may be too high

### 3. Expense Search Incomplete
- Total should be 35850 (Boris 14000 + Vika 5100 + Galya 11000 + Andrey 5750)
- Got only 6000 (partial data)
- Search not returning all expense items
