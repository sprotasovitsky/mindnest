## Critical Database Issues Found

### 1. SUPERSEDES Relation Wrong Target
```
[DELETED] Christmas tree → SUPERSEDES → "I have a Christmas tree, no need to buy."
```
Should be:
```
[DELETED] Christmas tree → SUPERSEDES → "We need the Christmas tree - artificial, 180cm"
```
The system deleted the wrong item!

### 2. Task Completion Not Working
Tasks have `[DONE]` in content but `status = TODO`:
```
"Mark my task as completed. [DONE]" - status = TODO
"My task is done! [DONE]" - status = TODO
"Task completed! [DONE]" - status = TODO
```
Should create new item with `status = DONE` and SUPERSEDES to original task.

### 3. Incorrect BELONGS_TO Relations
```
Expense: Duck → BELONGS_TO → [DELETED] Christmas tree
We need tree decorations → BELONGS_TO → [DELETED] Christmas tree
```
Completely wrong semantic linking.

### 4. Language Issues
Step 11: English question got Russian task names in response:
- "Купить весь алкоголь (шампанское, водка, вина)"

### 5. Search Returns Incomplete Data
Step 17 asked for expense summary:
