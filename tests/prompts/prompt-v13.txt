# Prompt Version 13
# Date: 2025-12-17
# Changes: Soft-delete + confirmation flow for delete operations

## Key Changes

### Soft-Delete
- Added `deletedAt` field to KnowledgeItem
- Delete sets timestamp instead of removing from DB
- Vectors removed from Qdrant (hard delete there)
- Repository queries filter `deletedAt IS NULL`

### Delete Confirmation Flow
- `delete-auto: 0.85` - similarity above this = delete without asking
- `delete-confirm: 0.65` - similarity above this but below auto = ask for confirmation
- Below 0.65 = no match found

### DeleteResult States
```java
enum Status {
    DELETED,           // Item was deleted (score > 0.85)
    NEEDS_CONFIRMATION, // Item found, needs confirmation (0.65 < score <= 0.85)
    NOT_FOUND          // No matching item found (score <= 0.65)
}
```

### Response Format
- DELETED: "Deleted: 'content...'"
- NEEDS_CONFIRMATION: "Found item to delete: 'content...' (X% match). Please confirm: should I delete this? [id: xxx]"
- NOT_FOUND: "No items found matching 'query' to delete"

## Thresholds (application.yml)
```yaml
agent:
  thresholds:
    deduplication: 0.85
    update: 0.6
    delete-auto: 0.85      # > this = delete without confirmation
    delete-confirm: 0.65   # > this = ask for confirmation
    task-search: 0.5
```
