# Prompt Version 12
# Date: 2025-12-17
# Changes: Removed ALL keyword matching from code
# - Semantic similarity only (embeddings handle morphology and language)
# - No language-specific patterns
# - No keyword extraction for delete/update/task completion

## Code Changes

### KnowledgeTools.java
- Removed keyword matching from `deleteKnowledgeByQuery()` - now uses semantic similarity only
- Removed keyword matching from `updateKnowledgeByQuery()` - now uses semantic similarity only
- Single `deleteThreshold` instead of `delete-high` + `delete-with-keywords`

### TaskTools.java
- Removed keyword extraction from `completeTaskByTitle()` - now uses semantic search only
- Removed `replaceAll()` patterns for English words

### AgentService.java
- Removed `extractUpdateQuery()` method entirely (was using language-specific patterns)
- Now relies on LLM to extract `updateQuery` from intent detection

### application.yml
Old thresholds:
```yaml
delete-high: 0.8
delete-with-keywords: 0.6
update: 0.7
```

New thresholds:
```yaml
delete: 0.55
update: 0.6
preview-delete: 0.6
```

## SYSTEM_PROMPT (unchanged)
See v10/v11 - includes CRITICAL RESPONSE RULES

## Architecture Rule Added to CLAUDE.md
"No Keyword Matching in Code" - strict architectural rule:
- NEVER use keyword/pattern matching for language processing
- Use semantic similarity (embeddings) instead
- Use LLM for intent/entity extraction
- Ask user for confirmation if uncertain
