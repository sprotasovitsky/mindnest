Analyze the user's message and determine their intent. Return JSON with:
- intent: one of SAVE, SEARCH, UPDATE, DELETE, TASK, COMPLETE, CHAT
- tool: which tool to call (or null for CHAT)
- content: the main content to save/search/update/delete (extracted from message)
- knowledgeType: for SAVE intent, one of FACT, NOTE, DECISION
- tasks: for TASK intent, array of task objects with {title, deadline, assignee}

*** MOST IMPORTANT RULE - CHECK FIRST ***

1. SEARCH - User asks a QUESTION or wants to find/retrieve info:

STOP! Before checking any other intent, check if the message is a QUESTION.
If ANY of these conditions are true, the intent is ALWAYS SEARCH (never SAVE!):

A) Message STARTS with a question word (any language):
   - Russian: что, какой, какие, какая, какое, сколько, когда, где, кто, почему, зачем, как, чё, че, чего
   - English: what, when, where, which, who, why, how, how much, how many

B) Message ENDS with "?" (question mark)

C) Message STARTS with a request word:
   - Russian: покажи, найди, выведи, подскажи, расскажи, скажи
   - English: show, find, list, tell me, search

*** EXAMPLES - ALL OF THESE ARE SEARCH, NOT SAVE: ***
- "Что мы покупали в этом месяце?" → SEARCH (starts with "что")
- "Какие у меня задачи?" → SEARCH (starts with "какие")
- "Сколько мы потратили?" → SEARCH (starts with "сколько")
- "чё там по бюджету?" → SEARCH (starts with "чё")
- "Покажи все расходы" → SEARCH (starts with "покажи")
- "What did we buy?" → SEARCH (starts with "what")
- "How much did we spend?" → SEARCH (starts with "how")
- "У меня есть задачи?" → SEARCH (ends with "?")

*** CRITICAL: Choosing the right SEARCH tool ***
- Use search_tasks ONLY if question explicitly mentions "задача", "задачи", "task", "tasks", "to-do"
- Use search_knowledge for EVERYTHING else: expenses, budget, purchases, spending, facts, notes

*** CRITICAL: content field for SEARCH ***
- For search_tasks: leave content EMPTY ("") for "show all tasks", or use specific task name
- For search_knowledge: use keywords describing what to find

EXAMPLES (tool + content):
- "Какие у меня задачи?" → tool: search_tasks, content: ""
- "Сколько мы потратили?" → tool: search_knowledge, content: "потратили расходы"
- "Что мы покупали?" → tool: search_knowledge, content: "покупки"
- "Покажи расходы" → tool: search_knowledge, content: "расходы"
- "чё там по бюджету?" → tool: search_knowledge, content: "бюджет"

*** OTHER INTENTS (check only if NOT a question) ***

2. TASK - User explicitly creates task(s):
- Pattern: "Create task for X: do Y" / "Задача для X: сделать Y" / "Создай задачу"
- Contains explicit task creation words: "задача:", "задачу", "create task", "add task"
Tool: create_task
Extract each task with title, assignee, deadline

3. COMPLETE - User marks a task as done:
- Contains: "выполнена", "сделана", "готово", "завершена", "закончил", "сделал задачу"
- Pattern: "X task is done" / "Задача X выполнена"
Tool: complete_task_by_title

4. DELETE - User wants to remove information:
- Contains: "удали", "убери", "отмени", "удалить", "remove", "delete"
- Example: "Удали информацию про заправку"
Tool: delete_knowledge
Extract search query in "content" field

5. UPDATE - User corrects/changes existing information:
- Contains: "на самом деле", "исправь", "измени", "не X а Y", "actually", "correct", "change"
- Patterns: "Actually it was 4200, not 4500"
Tool: update_knowledge
Extract update_query (what to find) and update_new_content (replacement)

6. SAVE - User provides NEW factual information (NOT a question!):
*** NEVER use SAVE if message is a question (check rule 1 first!) ***
- Expenses: "Потратил 500", "Купил X за Y", "I spent 500"
- Facts: "Бюджет 50000", "Встреча в 3 часа"
- Decisions: "Решили...", "Выбрали..."
Tool: create_knowledge

7. RELATION - User wants to link/connect items:
- Contains: "связь", "связать", "связано с", "зависит от", "connect", "link"
Tool: create_relation

8. CHAT - General conversation:
- "Привет", "Спасибо", "Hello", "Thanks"
Tool: null

User message: "%s"
